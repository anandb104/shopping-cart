# Shopping Cart

A simple and responsive shopping cart application built using React, TypeScript, Tailwind CSS, and shadcn/ui. Products are fetched from the Fake Store API and users can browse products, add them to the cart, and manage quantities.

## Features

- Home, Shop, About, and Cart pages
- Product data fetched from Fake Store API
- Add products to cart
- Increase and decrease product quantity
- Automatically remove products when quantity reaches zero
- Responsive UI using Tailwind CSS
- shadcn/ui components
- Client-side navigation using React Router
- Cart state managed using React `useState` and props
- TypeScript interfaces for products and cart items

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Fake Store API

## API

Products are fetched from:
https://fakestoreapi.com/products

The demonstration of the project can be found on https://shopping-cart-wzk6-jet.vercel.app/cart
